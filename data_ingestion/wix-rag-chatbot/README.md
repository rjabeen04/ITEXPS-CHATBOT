\# wix-rag-chatbot



A Retrieval-Augmented Generation (RAG) chatbot project that collects website content, cleans and chunks the text, creates embeddings, stores them in a vector database, and serves a chat experience through a backend API and frontend interface.



\## Setup Instructions



1\. Clone the repository:

&#x20;  git clone <your-repo-url>



2\. Go into the project folder:

&#x20;  cd wix-rag-chatbot



3\. Install dependencies:

&#x20;  pip install -r requirements.txt



4\. Copy the environment template:

&#x20;  cp .env.example .env



5\. Open `.env` and add your real credentials.
